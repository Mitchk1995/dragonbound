# Bark texture sources

The grown trees' bark (`src/render/foliage.ts`). Each was generated with Codex image generation as a softly painted,
tileable bark, then made to tile, toned and given its normal map by `tools/bark_textures.py`. The generated sources are
kept in `D:\dragonbound-archive\bark-src`.

| File | Source | Licence |
| --- | --- | --- |
| `oak.jpg` | Oak bark colour: deep vertical furrows between long plated ridges. Generated with Codex (`oak-bark.png`) for Dragonbound, October 3, 2026. | Project-owned artwork |
| `oak-normal.jpg` | Oak bark relief (OpenGL normal map), drawn from the oak bark source by `tools/bark_textures.py`. | Project-owned artwork |
| `tree.jpg` | Common tree bark colour: fine, shallow fissures. Generated with Codex (`tree-bark.png`) for Dragonbound, October 3, 2026. | Project-owned artwork |
| `tree-normal.jpg` | Common tree bark relief (OpenGL normal map), drawn from the tree bark source by `tools/bark_textures.py`. | Project-owned artwork |
